This Privacy Policy explains what data BloomBot collects, why we collect it, how it is stored, and what rights you have. BloomBot is created and operated by Mayflower Studios ("we", "us", "our").

The short version

BloomBot stores only the minimum data needed to make its features work (Discord IDs, XP counts, birthday dates you choose to share). We never read or store message content. We never sell or share your data with third parties.

1. Data We Collect

BloomBot collects and stores the following information in a local SQLite database. All data is scoped per-server (guild) — no data is shared across servers.

DataPurposeSource
Discord Server (Guild) ID Identify the server for per-server configuration and data storage Automatic (Discord API)
Discord User ID Track XP/levels, achievements, birthdays, and reaction role assignments per member Automatic (Discord API)
Discord Channel & Message IDs Store configured announcement channels and reaction role panel message references Server admin configuration
Discord Role IDs Map emoji reactions to roles in reaction role panels Server admin configuration
Birthday (month, day, optional year) Post birthday announcements on the correct date; optionally display age Voluntarily provided via /birthday set
XP, Level, Message Count, Reaction Count Power the leveling system, achievement tracking, and leaderboards Automatically counted from activity
Achievement Unlock Records Track which achievements a member has earned and when Automatically triggered by milestones
Twitch Usernames Monitor configured Twitch channels for live-stream announcements Server admin configuration
Server Configuration Settings Store feature toggles, custom messages, timezone, and channel assignments Server admin configuration

2. Data We Do NOT Collect

  • Message content — BloomBot never reads, logs, or stores the content of your messages. It only counts messages for XP and achievement purposes.
  • Direct messages — BloomBot does not monitor or store DMs.
  • Voice or video data — BloomBot has no voice features.
  • Email addresses, IP addresses, or personal identifiers beyond Discord IDs.
  • Data from other platforms — The Twitch integration only checks publicly available live-stream status; it does not access Twitch user accounts or profiles.

3. How Data Is Stored

All data is stored in a local SQLite database file on the server that hosts BloomBot. The database is not exposed to the internet and is not replicated to any cloud service or third-party storage provider.

4. Third-Party Services

BloomBot interacts with the following external services:

  • Discord API — to operate as a bot on the Discord platform. Subject to Discord's Privacy Policy.
  • Twitch Helix API — to check live-stream status for configured streamers. Subject to Twitch's Privacy Policy. No Twitch user data is stored beyond the configured usernames.

We do not share, sell, or transfer your data to any other third parties.

5. Data Retention & Deletion

Automatic

If BloomBot is removed from a server, server admins can request full deletion of that server's data. Data is not automatically purged upon bot removal, as accidental removals do happen — but we will delete it promptly on request.

User Requests

  • Remove your birthday at any time using /birthday remove
  • Request deletion of your leveling, achievement, and activity data by contacting us through the Mayflower Studios Discord

Server Admin Requests

Server administrators can request full deletion of all data associated with their server by contacting us. We will process deletion requests within a reasonable timeframe.

6. Children's Privacy

BloomBot is not directed at children under the age of 13. We do not knowingly collect data from anyone under 13. If you believe a child under 13 has provided data to BloomBot, please contact us and we will delete it promptly.

7. Discord Permissions

BloomBot requests the following Discord permissions to function:

  • Read Messages / Message Content — to count messages for XP (content is never stored)
  • Send Messages & Embed Links — to post announcements, level-ups, and achievement notifications
  • Manage Roles — to assign and remove reaction roles
  • Add Reactions — to set up reaction role panels
  • Read Message History — to track reactions on role panels
  • View Members — to detect joins/leaves for welcome messages and birthday checks

8. Changes to This Policy

We may update this Privacy Policy from time to time. The "Last updated" date at the top reflects the most recent revision. We will announce significant changes in our Discord community.
