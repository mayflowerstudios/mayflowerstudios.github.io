Quick Checklist

Requirements

  • Java Edition Minecraft

  • Modpack: Luna's Guns & Stuff
  • 6–8 GB RAM allocated

Common Fixes

  • Can't connect: verify you typed the IP exactly
  • Missing mods: update the modpack in CurseForge
  • Low FPS: lower shaders, set render distance 8–12
  • Crashes: drop your log in Discord and we'll help

🧩 Setup

Step-by-Step

1 · Install the Modpack

Find Luna's Guns & Stuff on CurseForge and install it. This is the easiest method — it keeps your version synced with the server automatically.

Open Modpack Page ↗

1B · Direct ZIP Install

If you downloaded the server ZIP directly, choose your install method below.

CurseForge Import
  1. Open CurseForge → Minecraft → My Modpacks
  2. Look for Import or Create Custom Profile → Import
  3. Select the ZIP you downloaded, wait for install, click Play
Prism Launcher
  1. Open Prism → Add Instance → Import from zip
  2. Select the downloaded ZIP
  3. Let it set up, then click Launch
Manual (fallback — only if ZIP contains mods/config folders)
  1. Extract the ZIP
  2. Install Minecraft Forge 1.20.1
  3. Copy mods/, config/, kubejs/ into your .minecraft folder
  4. Launch the Forge profile and join

2 · Launch Minecraft

Launch from CurseForge (or your imported instance). Allocate 6–8 GB RAM in your launcher settings for the best experience.

3 · Add the Server

In Minecraft: Multiplayer → Add Server. Paste the address below.

play.mayflowerstudios.net

4 · Join & Say Hi 👋

If you get kicked for a missing mod, you're on the wrong modpack version — update and try again. Otherwise, welcome!
