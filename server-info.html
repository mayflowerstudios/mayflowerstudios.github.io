🧩 Step-by-step

Fast setup

1) Install the Modpack (CurseForge)

Install Luna’s Guns & Stuff through CurseForge. This is the easiest method and keeps versions synced.

Open Modpack Page

1B) Install using the Direct Download (ZIP)

This is a “grab the exact pack we’re running” option. Download the ZIP, then install it using one of the methods below.

Method A: CurseForge Import (best if the ZIP is a CurseForge export)
  1. Click 📦 Direct Download (ZIP) at the top of this page.
  2. Open the CurseForge app.
  3. Go to Minecraft → My Modpacks.
  4. Look for an Import option:
    • Either a button like Import / Import Profile, or
    • Create Custom Profile → Import
  5. Select the ZIP you downloaded.
  6. Wait for it to install, then click Play.

If CurseForge says the ZIP is invalid: that usually means the ZIP isn’t a CurseForge export (missing manifest.json). Use the Prism method below instead — it’s super reliable.

Method B: Prism Launcher (very reliable for direct packs)
  1. Install Prism Launcher if you don’t have it yet.
  2. Click Add Instance.
  3. Choose Import (or Import from zip).
  4. Select the ZIP you downloaded from this page.
  5. Let it set up the instance, then click Launch.

Prism is usually the easiest way to use a “direct pack ZIP” when CurseForge import is picky.

Method C: Manual Install (fallback — only if the ZIP contains mods/config)

Only use this if the ZIP includes folders like mods, config, kubejs, etc. (If it’s a CurseForge export ZIP, use Import instead.)

  1. Download the ZIP and extract it somewhere (Right-click → Extract All).
  2. Install Minecraft Forge 1.20.1 (must match the server’s Forge version).
  3. Open your Minecraft folder:
    • Windows: %appdata%\.minecraft
  4. Copy the extracted folders into your Minecraft folder:
    • Copy mods → .minecraft\mods
    • Copy config → .minecraft\config
    • Copy kubejs → .minecraft\kubejs (if present)
  5. Launch the Forge profile, then join the server.

If manual install sounds annoying, ping us in Discord and we’ll point you to the easiest method for your launcher.

2) Launch Minecraft

Launch from CurseForge (or your imported instance). Make sure you have 6–8GB RAM allocated if needed.

3) Add the Server

In Minecraft: Multiplayer → Add Server
Address: play.mayflowerstudios.net

4) Join & Say Hi 👋

If you get kicked for a missing mod, you’re likely on the wrong modpack version. Update/reinstall the pack and try again.
