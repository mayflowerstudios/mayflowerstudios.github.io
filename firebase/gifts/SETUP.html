Enable gift uploads

This is a one-time update. Afterward, add images from Admin → Gifts and they will appear in the gift picker without another website update.

  1. Open the complete database rules. Copy them into Firebase → Realtime Database → Rules, then choose Publish.
  2. Open the complete Storage rules. Copy them into Firebase → Storage → Rules, then choose Publish.
  3. Return to Admin → Gifts and choose Refresh. Add your images, choose a category, then choose Add gifts.

These files start from the rules you supplied. Changes add an administrator-managed gift catalogue, image uploads, and image gifts without a required emoji. If your live rules have changed since that copy, merge the gift-related sections into the current rules first. Firestore rules are unaffected.
