🔧 Setup Notes

Keep it fun, keep it stable
Recommended flow

Start simple: enable one or two core loops (XP + raids), then add lore/events once the server rhythm settles.

Suggested setup: - Create realm roles + a realm-selection entry point - Enable XP + basic raids first - Add ranks/role automation once balance feels right - Introduce seasonal events after the community stabilizes
