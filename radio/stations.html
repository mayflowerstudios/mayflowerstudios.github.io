🌿 Listed stations

Tune in

Stations run from their owner's own computer, so one is only listenable while that person has Mayflower Radio open. If a station won't load, it's most likely just off the air for now.

Want your station listed here? Open Mayflower Radio, go to Tools → Settings → Public listing, and tick "List my station on the public stations page". Give it a name and a line about it, save, and it appears here by itself — with a live "On air" badge while you're broadcasting. Untick it (or close the app) and the listing goes away again.

Worth knowing before you do: a station address includes the host's home internet (IP) address, so listing it makes that public to anyone visiting this page. Only turn it on if you're comfortable with that.
