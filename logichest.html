📝 Description

What LogiChest is

LogiChest is a lightweight Forge mod that adds a clean logistics layer to survival storage. You build a Hub to act as the router, then attach Sorters that define what items should be routed and where they should be delivered.

The goal is simple: keep storage automation readable, predictable, and survival-friendly—without turning your base into a complex pipe network.

🔗 How routing works (for real)

The Hub pulls items from the inventory directly in front of it (the direction the Hub is facing). Each linked Sorter points at a destination inventory (the container in front of the Sorter). If an item in the Hub’s source matches a Sorter’s filters, the Hub moves it into that Sorter’s destination.

🗝️ Link Keys

Link Keys are crafted inside the Hub over time and become bound to that specific Hub (ID + position + dimension). Put a Link Key into a Sorter to link it. If the Hub is at its maximum linked sorters, the link is rejected.

📦 Filter whitelist (10 slots)

Each Sorter has 10 ghost filter slots. Filters match by item type (NBT isn’t considered). Only items that match a Sorter’s filter list are eligible to be routed to it.

⚙️ Server-friendly defaults (configurable)

LogiChest includes a Forge config to tune pacing and limits. Default values:

  • Max linked sorters per Hub: 8
  • Hub transfer cooldown: 8 ticks (vanilla hopper speed)
  • Transfers per cycle: 3 (moves up to 3 distinct item types per eligible sorter per cycle)
  • Link Key craft time: 600 ticks (30 seconds)
Best used for

Storage rooms, farm outputs, smelter lines, and “loot intake” systems where you want clean routing without complexity.

⭐ Highlights

What LogiChest is about

📦 Hub → Sorter Routing Core

The Hub routes items from its facing inventory to sorter destinations based on sorter filter whitelists.

  • Round-robin fairness across linked sorters
  • Routes only if the sorter has filters set
  • Per-sorter cooldowns so upgrades matter

🧩 Upgrade-based Scaling Polish

Sorters have 4 upgrade slots that change how much they move/craft and how fast they operate.

  • Speed Coils: faster routing + faster autocrafting
  • Stack Boosters: larger batch size per item type
  • Autocrafter Core: crafts from hub inventory into sorter output
  • Keychain Module: authorize a sorter for multiple hubs

📘 How to Use

Quick setup flow

1) Decide your “source” inventory

The Hub pulls from the container it is facing.

  • Example sources: a chest that receives farm output, a buffer chest, a drop-off chest
  • Place the Hub so it is facing that container
  • That facing container becomes the Hub’s input source

2) Place Sorters at destinations

Each sorter points at the container it should fill.

  • Put a Sorter next to a destination chest/barrel
  • Make the Sorter face the destination container
  • That facing container becomes the sorter’s output destination

3) Create a Link Key in the Hub

The Hub crafts keys over time using a simple recipe.

  • Insert the Link Key ingredients into the Hub crafting slots
  • Wait for progress to complete (configurable time)
  • The crafted Link Key is bound to that Hub

4) Link Sorters & set filters

Link keys connect a sorter to a hub, filters decide what it accepts.

  • Put the Link Key into the sorter’s link slot
  • Set the sorter’s 10 filter slots (ghost items)
  • Now the Hub can route matching items into that sorter’s destination
