📝 Description

What LogiChest is

LogiChest is a survival-friendly storage routing system built around a central Hub and a network of Sorters. Instead of endless hoppers and messy spaghetti, you get clean routing, readable setups, and modular upgrades — designed for long-running worlds and multiplayer reliability.

Philosophy

Automation that stays understandable. Progression that feels earned. Systems that don’t break your base.

📘 How to Use

Quick setup flow

1) Place the Hub

Your Hub is the brain of the network.

  • Place the Hub near your main storage area
  • Open it to view connected sorters and settings
  • Think of it as the “router” for item traffic

2) Add Sorters

Sorters do the actual filtering and delivery.

  • Place a Sorter near a chest/barrel (or wherever it outputs)
  • Configure what the sorter accepts (filters)
  • Each sorter represents a “lane” for certain item types

3) Link Sorters to the Hub

Connect devices so the Hub can route to them.

  • Use the mod’s linking flow (item/tool or UI link action)
  • Confirm the Hub shows the sorter as connected
  • Repeat for each storage category (blocks, ores, food, etc.)

4) Feed Items In

Send items to the Hub and let it route them.

  • Insert items into the Hub input (or attached input)
  • The Hub finds a matching sorter and routes automatically
  • Unmatched items follow your configured fallback behavior
