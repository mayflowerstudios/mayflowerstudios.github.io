🧠 LogiChest

LogiChest is a modular storage logistics mod: place a Hub, connect Sorters, and let your items move where they belong. It’s designed to keep bases clean, storage organized, and automation simple without turning Minecraft into a spreadsheet.

📦 Download LogiChest 🧾 Source / Issues

✨ Description

LogiChest helps you build an item-routing network with a central Hub and connectable Sorters. Use upgrades to expand capacity, add modules, and tailor how your network behaves.

  • Hub + Sorters: build a simple network that routes items automatically.
  • Modular upgrades: add functionality without rebuilding everything.
  • Clean & predictable: designed for survival bases and servers.
  • Expandable: scale from a tiny starter setup to a full storage room.
Tip: Start with 1 Hub + 1–2 Sorters, confirm it works, then scale up. It’s way easier to debug small.

🧭 How to Use

Here’s the usual LogiChest flow:

  1. Craft and place a Hub in your storage room.
  2. Craft a Sorter and place it near the container it will manage.
  3. Link the Sorter to the Hub (see linking steps below).
  4. Configure the Sorter (filters / targets / priorities as your mod supports).
  5. Feed items into the system and watch them route into the correct chests.
  6. Add upgrades to expand sorter slots, hub capacity, or behavior modules.
Basic Setup
Hub → Sorter (linked) → Chest / Barrel / Drawer
Scaling Up
Hub → Sorter A (ores) → chest wall
Hub → Sorter B (food) → kitchen storage
Hub → Sorter C (mob drops) → bulk storage
Quick troubleshooting: If a sorter says it’s linked but nothing moves, double-check: range, filters, inventory permissions, and whether the hub is at max connections.
