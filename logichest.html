📝 Description

What LogiChest is

LogiChest is a lightweight Forge mod that adds a clean logistics layer to survival storage. You build a Hub to act as the router, then attach Sorters that decide what items should be routed and where they should be delivered.

The goal: keep automation readable, predictable, and server-friendly — without turning your base into a spaghetti pipe network.

🔗 How routing works (simple, real, reliable)

The Hub pulls items from the inventory directly in front of it (the direction the Hub is facing). Each linked Sorter points at a destination inventory (the container in front of the Sorter). If an item in the Hub’s source matches a Sorter’s filters, the Hub moves it into that Sorter’s destination.

🗝️ LogiLink Keys (Hub-bound)

Link Keys are crafted inside the Hub over time and become bound to that specific Hub (ID + position + dimension). Put the key into a Sorter’s link slot to connect it. If the Hub is at max linked Sorters, the link is rejected.

Hub key ingredients

The Hub crafts a LogiLink Key using: Iron Ingot + Redstone + Amethyst Shard (craft time is configurable).

📦 Filter whitelist (10 slots)

Each Sorter has 10 ghost filter slots. Filters match by item type (NBT isn’t considered). Only items that match a Sorter’s filter list are eligible to be routed into it.

⚙️ Upgrades (4 slots, stackable where it matters)

Each Sorter has 4 upgrade slots. Some upgrades can stack to scale performance and throughput.

  • Speed Coil: reduces routing/autotick cooldown (faster sorting and faster craft/smelt intervals). Stacks (up to 8 per stack).
  • Stack Booster: increases how many items move per batch (base 1 + boosters). Stacks (up to 8 per stack).
  • Autocrafter Core: enables crafting from Hub inventory directly into the sorter’s destination container.
  • Autosmelter Core: enables smelting from Hub inventory into the sorter’s destination container (fuel is pulled from the Hub, furnace-style).
  • Keychain Module: adds a built-in 9-slot keychain inventory so the sorter can authorize multiple hubs.

🧷 Keychain Module (multi-hub authorization)

Install the Keychain Module to give the sorter a hidden 9-slot keychain inventory. Put multiple Hub-bound Link Keys into it and the sorter can register with multiple hubs (as long as each hub has capacity).

Bonus: the Keychain Module item itself can be right-clicked to open its own 9-slot GUI (handy for managing keys).

🔥 Autosmelting (fuel handled “like a furnace”)

With Autosmelter Core installed, the sorter can smelt items using real fuel burn time rules. Fuel is pulled from the Hub inventory (and container items like buckets are returned when possible). Output goes to the sorter’s destination container.

🧊 Server-friendly defaults (configurable)

LogiChest includes a Forge server config to tune pacing and limits. Defaults:

  • Max linked sorters per Hub: 8
  • Hub transfer cooldown: 8 ticks (vanilla hopper speed)
  • Transfers per cycle: 3
  • LogiLink Key craft time: 600 ticks (30 seconds)
Best used for

Storage rooms, farm outputs, smelter buffers, and “loot intake” systems where you want clean routing without complexity.

📘 How to Use

Quick setup flow

1) Decide your “source” inventory

The Hub pulls from the container it is facing.

  • Example sources: farm output chest, buffer chest, drop-off chest
  • Place the Hub so it faces that container
  • That facing container becomes the Hub’s input source

2) Place Sorters at destinations

Each sorter points at the container it should fill.

  • Put a Sorter beside a destination chest/barrel
  • Make the Sorter face the destination container
  • That facing container becomes the sorter’s output destination

3) Craft a LogiLink Key in the Hub

The Hub crafts keys over time using 3 ingredients.

  • Put Iron Ingot, Redstone, Amethyst Shard into the Hub inputs
  • Wait for the progress to finish (default: 30s)
  • The key is bound to that Hub (ID + pos + dimension)

4) Link Sorters & set filters

Link keys connect a sorter to a hub, filters decide what it accepts.

  • Put the LogiLink Key into the sorter’s link slot
  • Set the sorter’s 10 filter slots (ghost items)
  • The Hub will route matching items into that sorter’s destination

5) Add upgrades (optional)

Scale routing, enable crafting, or enable smelting.

  • Speed Coils: faster cycles
  • Stack Boosters: bigger batches
  • Autocrafter/Autosmelter: craft or smelt from Hub inventory into output

6) Multi-hub sorters (Keychain Module)

Authorize one sorter for multiple hubs by storing multiple keys.

  • Install Keychain Module in the sorter upgrade slots
  • Open it and insert multiple LogiLink Keys
  • Sorter registers with each hub (if each hub has space)
