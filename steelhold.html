📝 Description

What Steelhold is

Steelhold is a Forge mod that adds player-owned safes with a practical lock-and-key workflow. When a safe (or Steelhold Door) is placed, it stores an Owner and a unique Lock ID. The owner can open it freely; everyone else needs a matching key.

Steelhold is built for survival pacing and server longevity: safes can be tuned via config, support multiple tiers, and behave like real heavy objects — if you remove the block underneath, they fall like anvils.

🔑 Keys (Craft → Bind → Share)

Keys are crafted as blanks, then bound by right-clicking a safe/door you own.

Once bound, keys store the Lock ID in NBT and can open any Steelhold block that shares that lock (safes + doors). Tooltips show a short lock ID and extra context so you can manage multiple keys without losing track.

🧰 Upgrade Kits (In-Place Upgrades)

Upgrade kits let you right-click a safe to upgrade it to the next tier without picking it up. The upgrade preserves the important stuff: inventory, custom name, owner, and Lock ID.

  • Reinforced Upgrade Kit: Basic → Reinforced
  • Steelhold Upgrade Kit: Reinforced → Steelhold
  • Vault Upgrade Kit: Steelhold → Vault (2-block tall)
  • Bank Upgrade Kit: Vault → Bank (2×2×2 structure)
Space checks included

Upgrades that expand into multi-block safes verify space first, so you don’t accidentally overwrite blocks.

🚪 Steelhold Door (Locked + Alarm + Redstone)

The Steelhold Door is a locked iron door that uses the same ownership + key system as safes. If a non-owner tries to open it, it can trigger an alarm state and emit a strong redstone signal.

  • Alarm output: emits redstone while alarm is active (great for sirens, lights, or alerts).
  • Optional redstone open: config can allow or deny opening via button/lever.
  • Tool requirement: configurable pickaxe level gate for proper drops/breaking behavior.

⬇️ Falling Safes (Anvil-Style Physics)

Safes are heavy: if the block under them disappears, they convert into a falling block entity (like anvils) and keep their stored data while falling/landing — including inventory, owner, and lock ID.

🏗️ Sizes & Structure

  • Basic / Reinforced / Steelhold: single-block safes.
  • Vault Safe: a 2-block-tall safe placed as a lower + upper half.
  • Bank Safe: a 2×2×2 “mega safe” (8 blocks). Only the origin block stores the inventory and drives the structure.

⚙️ Configurable Balance

Steelhold ships with a Forge common config that lets pack makers and servers tune: slot counts, hardness, blast resistance, and required pickaxe tier per safe tier. There are also global toggles for whether safes drop contents on break and whether explosions can destroy Steelhold blocks.

Note: slot counts won’t shrink existing safes

Slot settings apply to newly placed safes only. Existing safes keep their original size to prevent item loss.

📘 How to Use

Quick gameplay guide

1) Craft & Place

Place a safe (or Steelhold Door) like any block — it binds to the player who placed it.

  • Owner is stored on the block
  • Each gets a unique Lock ID
  • Vault is 2-block tall; Bank is a 2×2×2 structure

2) Craft Keys, Then Bind (Owner)

Make blank keys, then right-click the safe/door you own to bind.

  • Craft: Steelhold Key
  • Right-click your safe/door to bind
  • Share bound keys with trusted players

3) Upgrade In-Place (Optional)

Use upgrade kits to step safes up without moving items around.

  • Right-click a safe with the correct kit
  • Preserves inventory + lock data
  • Expanding tiers check for space

4) Alarms & Automation (Door)

Use the door alarm redstone output to wire up a security system.

  • Intrusion attempts can trigger alarm mode
  • Alarm emits redstone while active
  • Config can allow/deny redstone opening

⌨️ Commands

Admin + debugging utilities

Steelhold includes a small set of server commands for management and testing (you must be looking at the safe/door within 5 blocks).

/steelhold resetlock → owner-only: resets the Lock ID (old keys stop working) /steelhold whoowns → shows current owner (safe or door) /steelhold setowner <player> → admin/tooling: set the owner (safe or door) /steelhold fakeintrusion → triggers the alarm (safe/bank/vault/door) for testing
Resetting a lock invalidates old keys

Use /steelhold resetlock if a key gets stolen or you’re rotating access rules on a server.
