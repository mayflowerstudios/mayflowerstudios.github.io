# Gift upload test images

Three additional gifts generated with the built-in image-generation tool for Mayflower Studios. Original PNG files preserve alpha transparency.

In Admin → Gifts, drop in any of the PNG images in this folder, choose a category, and select Add gifts. Names are filled from filenames; no emoji is required.

These three images are also registered in the bundled catalogue under **Cozy**. Their published copies are in `assets/gifts/Cozy/`; this folder keeps the originals and generation prompts. Uploading these originals through Admin adds separate copies to the catalogue.
