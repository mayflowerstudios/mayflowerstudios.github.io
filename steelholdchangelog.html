v1.2.1 Bug fixes and upgrade items

Added: • Upgrade items to just right click a safe to upgrade it instead of needing to break them first to use in crafting.
Changed: • Doors can now be renamed like the safes.
Fixed: • Door issue with not dropping items. Doors now drop the item when broken.

v1.2.0 DOORS!

Added: • Added a door that locks just like the safes do.
• The doors can also give off a redstone signal when used without the key just like the safes.

v1.1.1 Bug fixes plus some changes

Added: • Safes now emit a redstone signal when trying to open with the wrong key so you can set up an alarm/trap system for them.
Changed: • No longer uses a command to make a key. You craft unbound keys and right click your safe to bind it.
• Crafting recipes have changed making them easier to make but still balanced.
Fixed: • Vault safe breaking texture for the top block is fixed.

v1.1.0 Safe Size Update

Changed: • Vault safe is now a 2 block tall safe.
• Bank safe is now a 2x2x2 safe.
Known Issues: • There are some texture issues with the Vault safe that are being looked into.

v1.0.0 Initial

Added: • Core secure storage system, first safe blocks, key/ownership foundation.
