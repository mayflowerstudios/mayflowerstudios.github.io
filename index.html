✨ Who's behind it

About the studio

Mayflower Studios is a one-person indie studio. I build small, deliberate projects — the kind of things I'd actually want to use with the people I care about. No bloat, no roadmaps a mile long; just a few cozy tools and stories, polished until they feel right.

Every project starts with the same question: "Would this make a moment with someone a little better?" That keeps the scope honest and keeps the magic in.
