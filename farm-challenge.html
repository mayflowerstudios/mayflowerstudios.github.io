📝 About the Mod

Build the run you want

Farm Challenge turns Farming Simulator 25 into a structured challenge game without making you leave the save or manage goals on a separate spreadsheet.

One row at the top decides what you are playing. Pick a premade and every setting below fills itself in; pick Custom setup and build the run yourself — starting money, starting loan, borrowing limit, time limit, economy difficulty, final goal, and three milestones, each with its own metric, target, and deadline down to the quarter.

Change anything about a premade and it simply becomes your own custom run, named by you. The premade itself is never modified, so it is always there to start again from.

Existing money, assets, and owned fields still count toward the conditions, while the editor only offers targets above the value your farm will have once your chosen starting money and debt are applied — so a run can never be finished the moment it starts. A premade target that sits below that line is raised for you automatically. Starting cash is excluded from earned-income progress, and so are loans and asset sales: money earned means money the farm actually made.

Every active run has a full win, failure, or abandon lifecycle. Completed runs are saved to a history attached to that savegame and farm, and the Randomize button can roll an entire surprise challenge when you do not feel like building one manually.

⭐ Features

Everything included
Goals

🎯 Three Goal Types

Build the challenge around the kind of progress you care about.

  • Grow your farm’s net worth
  • Own a chosen number of fields
  • Earn a chosen amount of money
Progression

🏁 Configurable Milestones

Use three milestones to create a full progression path instead of one distant finish line.

  • Deadlines down to the quarter
  • Live progress bars in the menu
Premades

🧰 Ten Ready-Made Challenges

From a quiet Tiny Homestead to the eight-year Zero Cash Climb, each with its own rules, deadlines, and starting conditions.

  • Choosing one fills in every setting below it
  • Play it as-is, or use it as a starting point
  • Editing a premade turns it into your own custom run
Rules

🚫 Six Restrictions

Turn normal conveniences off and make each decision matter more.

  • No hired workers or contract machines
  • No leasing, fast travel, or new loans
  • No GPS or steering assist
  • Optional borrowing limit instead of a full loan ban
Multiplayer

👥 One Challenge Per Farm

Every farm on the server runs its own challenge, or none at all — kept in sync by the server.

  • A farm manager or the server admin starts and clears the run
  • Everyone on that farm sees the same live progress
  • Rules only apply to the farm that chose them
Tracking

📚 Per-Save Run History

Challenges belong to the savegame and farm where they were created, and remain easy to review later.

  • Win, fail, or abandon summaries
  • Challenge state persists across restarts
  • Randomized challenge generation

📘 How It Works

From setup to finish

1) Open Farm Challenge

Open the Farm Challenge page from the Farming Simulator 25 Escape menu.

2) Pick a Premade, or Custom

Choose a premade and the settings below fill themselves in. Choose Custom setup to build the economy, deadline, goal, milestones, and restrictions yourself — or let Randomize choose everything.

3) Create and Start

A premade keeps its own name; a custom run asks you for one. In multiplayer this is the farm manager’s call, and it starts the challenge for that whole farm.

4) Track It Live

Follow the progress bars in the menu or press Left Shift + J to toggle the HUD. The binding can be changed in the game controls.

5) Complete the Challenge

Reach the final goal before time expires. The result and completion summary are saved in the run history.

Change your mind

Adjust any row and the picker returns to Custom setup — you are no longer playing the premade, so the run becomes yours to name.

📥 Install

Keep the ZIP intact
Works in single-player and multiplayer

In multiplayer everyone needs the mod — the server and every player joining it, all on the same version. The server keeps each farm’s challenge and decides the results; each player’s copy draws the Farm Challenge page and the HUD.

1) Download FS25_FarmChallenge.zip
2) Do not extract the ZIP
3) Place it in:
   Documents\My Games\FarmingSimulator2025\mods
4) Enable “Farm Challenge” when loading your save
5) Open the Escape menu and choose the Farm Challenge page

For multiplayer: repeat this for the server and for every
player who joins it, using the same version of the ZIP.
