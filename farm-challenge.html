📝 About the Mod

Build the run you want

Farm Challenge turns Farming Simulator 25 into a structured challenge game without making you leave the save or manage goals on a separate spreadsheet.

Choose your starting money, starting loan, time limit, economy difficulty, final goal, and up to three milestones. Existing money, assets, and owned fields still count, while the setup menu prevents you from choosing targets that would already be completed when the run begins. Starting cash is also excluded from earned-income progress.

Every active run has a full win, failure, or abandon lifecycle. Completed runs are saved to a history attached to that savegame, and the Randomize button can roll an entire surprise challenge when you do not feel like building one manually.

📘 How It Works

From setup to finish

1) Open Farm Challenge

Open the Farm Challenge page from the Farming Simulator 25 Escape menu.

2) Build or Randomize a Run

Set the economy, deadline, goal, milestones, and restrictions—or let the Randomize button choose everything.

3) Track It Live

Follow the progress bars in the menu or press Left Shift + J to toggle the HUD. The binding can be changed in the game controls.

4) Complete the Challenge

Reach the final goal before time expires. The result and completion summary are saved in the run history.

📥 Install

Keep the ZIP intact
Farming Simulator 25 single-player mod

The current release declares multiplayer support as disabled.

1) Download FS25_FarmChallenge.zip
2) Do not extract the ZIP
3) Place it in:
   Documents\My Games\FarmingSimulator2025\mods
4) Enable “Farm Challenge” when loading your save
5) Open the Escape menu and choose the Farm Challenge page
