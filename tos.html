1. What BloomBot Does

BloomBot is a community-focused Discord bot that provides the following features:

  • Welcome & Leave Messages — customizable greetings and farewell messages when members join or leave a server
  • Birthday Tracking — members can register their birthday (month, day, and optionally year) for server-wide announcements
  • Leveling & XP — message-based experience points and level progression with leaderboards
  • Achievements — milestone-based badges unlocked through server activity
  • Reaction Roles — self-assignable roles via emoji reactions on configured panels
  • Daily Affirmations — scheduled positive messages posted to a designated channel
  • Twitch Stream Announcements — automatic notifications when configured Twitch streamers go live
  • Easter Eggs — fun hidden responses and interactions
