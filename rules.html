📜 Server Rules

Keep it fun. Keep it fair. Don’t be weird. These rules exist so everyone can build, explore, and cause reasonable chaos without ruining the server.

🛰️ Back to Server Dashboard 🏠 Home

✅ The Big 6

Memorize these and you’re basically golden
  1. Be respectful. No harassment, hate speech, targeted bullying, or slurs.
  2. No cheating. No hacked clients, x-ray, dupes, item hacks, or exploit abuse.
  3. No griefing. Don’t destroy or steal from other players’ builds without permission.
  4. PvP is consent-based. Unless it’s a scheduled event/arena, ask first.
  5. Keep performance sane. Avoid lag machines, runaway farms, or chunkloader spam.
  6. Staff calls are final. We’ll be fair, but we will also bonk repeat offenders.

🏡 Claims, Builds, and Griefing

Build cool things; don’t torch other people’s cool things
  • No griefing (lava, TNT, fire, explosions, withers, etc.) in or near someone’s build.
  • No theft. Don’t “borrow” resources from bases, chests, vehicles, or machines.
  • If you find an unclaimed stash/structure, ask before taking.
  • Spawn is protected. Don’t clutter spawn with random junk or trap builds.
  • Large builds are welcome — just don’t block paths, portals, or community areas.

🔫 Guns, Vehicles, and PvP

Yes, this pack has toys. No, you can’t be a menace 24/7.
  • No spawn camping. Don’t ambush new players or repeatedly target the same person.
  • No random drive-bys. Shooting bases/players without consent counts as griefing.
  • PvP requires consent unless it’s a server event, duel, or designated arena.
  • Vehicles: don’t ram builds, block entrances, or park on top of someone’s stuff.
  • Events/arenas: rules may change per event — the event post is the rulebook.
Tip: if you want “always-on PvP”, we can designate a region/arena where it’s automatically allowed.

⚙️ Performance Rules

Help the server not melt
  • No lag machines. Redstone clocks, infinite loops, or spammy contraptions get removed.
  • Farms are fine — but keep them reasonable. If it tanks TPS, we’ll ask you to optimize it.
  • Chunkloaders: use sparingly. Don’t keep half the world loaded 24/7.
  • Mob caps: don’t build “spawn everything forever” grinders that cause entity floods.
  • If staff asks you to tweak a build for performance, please do it — we’ll help you.

💬 Chat & Community

Vibes matter
  • No hate speech, bigotry, or targeted harassment.
  • No doxxing, threats, or sharing private info.
  • Keep spam to a minimum (caps, repeated messages, mic spam if voice chat is used).
  • PG-13-ish is the goal. If you wouldn’t say it in a mixed group, don’t.

🛠️ Enforcement

How we handle rule breaks

We usually follow this ladder, depending on severity:

  • Warning (with what to change)
  • Rollback / removal (grief, stolen items, lag builds)
  • Temporary mute/kick
  • Temporary ban
  • Permanent ban (for repeat issues or severe behavior)

If something goes wrong or you think a call was unfair, ping staff in Discord. We’ll talk it out.

🧾 Quick FAQ

Stuff people always ask

Can I prank? Light pranks are okay if they’re reversible and not destructive. If it causes stress or mess, it’s griefing.

Can I raid bases? Not unless it’s a planned event with explicit rules.

Can I build big farms? Yes — just don’t lag the server. If it’s heavy, we’ll help optimize.

What about explosives? Use responsibly. No TNT/wither near builds, spawn, or community zones.
