📝 Description

What EchoBloom is (in our server)

EchoBloom is our private “living world” bot. Members choose one of four realms and then build progress through lightweight daily play: quick adventure commands, realm inventory drops, skill XP, and server events like Reaction Battles and Realm Raids.

It’s designed to feel like an RPG layer on top of chat — not a grindy spreadsheet. Most actions are short, readable, and server-paced (with cooldowns + optional buffs).

🌿 The Four Realms

Realm identity is a real system: roles, level/Xp tracking, and realm-only crafting.

⭐ Core Systems

What makes EchoBloom EchoBloom

🌿 Realm Progression Core

Realms track both realm-wide progress and individual member progression.

  • Join realms via a reaction-based realm message
  • Realm roles are assigned automatically
  • Rank roles can be applied for starting level
  • Realm/member leaderboards available

🧭 Adventures + Skills Daily

Adventure commands generate realm drops and skill XP. These are the “bread and butter” loops.

  • /forage, /hunt, /fish, /explore, /mine, /gather
  • Cooldown-based pacing (base is short; buffs can reduce it)
  • /skills shows skill levels & progress

⚔️ Realm Raids Event

Realms can raid other realms in an interactive reaction event (attackers vs defenders).

  • /raid starts a realm-vs-realm raid
  • Participants react ⚔️ (attack) or 🛡️ (defend)
  • Raid success steals a portion of non-seasonal items
  • Realm cooldown after raids (server-paced)

🛠️ Crafting + Realm Buffs Strategy

Craftables are realm-specific and apply timed buffs (XP boosts, drop boosts, cooldown reductions).

  • /craft to activate a crafted realm buff
  • /craft_list and /craft_info for recipe browsing
  • /buffs shows active effects & remaining time
  • Examples: Verdant Totem, Blazing Warbrand, Reflected Sigil, Lunar Concord

📘 How to Use

Quick gameplay flow

1) Join a Realm

Pick a realm by reacting on the realm-selection message.

  • Mods set the message with /setrealmmessage
  • React with the realm emoji to join
  • EchoBloom assigns your realm role automatically

2) Run Adventures

Use the short adventure commands to generate drops and progress.

  • Try: /forage, /hunt, /fish
  • Also: /explore, /mine, /gather
  • Cooldowns keep it paced (and can be reduced by buffs)

3) Track Progress

Check your realm, your rank, and your skills.

  • /rank shows your personal level/XP
  • /realmstats and /realmleaderboard show realm standings
  • /skills shows skill levels + XP

4) Inventory, Crafting, and Events

Use your realm inventory for crafting buffs and participating in events.

  • /realminventory to view realm stash (paged UI)
  • /craft to consume items and activate a realm buff
  • /raid to initiate a realm raid (realm cooldown applies)
  • /event + /offerrelics for seasonal systems

Most-used commands (player + mod)

  • /rank — your level/XP
  • /realmstats, /realmleaderboard, /realmmembers
  • /forage, /hunt, /fish
  • /explore, /mine, /gather

  • /craft, /craft_list, /craft_info, /buffs
  • /raid — realm raid event
  • /gift, /trade — realm-to-realm item movement
  • /event, /offerrelics — seasonal systems

🛡️ Mod / Admin Commands Staff

These are permission-gated (manage guild / admin / manage messages).

  • /setrealmmessage — sets realm selection message + adds reactions
  • /trigger_reactionbattle — starts a reaction battle manually
  • /mod_add_item, /mod_remove_item, /mod_set_item
  • /mod_view_inventory — view realm stash
  • /postlore — posts realm-year lore to its lore channel
  • /restart — restarts EchoBloom

🔧 Setup Notes

Start clean, keep it readable
Recommended rollout

Enable realms + adventures first. Once the server rhythm feels good, introduce crafting buffs and then raids/events.

Suggested setup: - Create the realm roles (one per realm name) - Post a realm selection message and run /setrealmmessage on it - Make a channel for event popups if you want events centralized - Encourage daily play loops: /forage, /hunt, /fish, etc. - Once inventories grow, introduce /craft and realm buffs - Finally, bring in /raid and seasonal systems
