What is EchoBloom?

Description

EchoBloom is our private "living world" bot. Members choose one of four realms and build progress through daily conversation and voice chat — every message earns XP for you and your realm, items drop randomly, lore fragments surface from the noise, and realm events can trigger at any moment.

On top of that sits a full class system — eight archetypes that shape how you earn XP, find items, contribute to your realm, and perform in combat. Prestige into new classes at cap to carry permanent stat bonuses forward. Master all eight to earn the 🏆 Class Master title.

It's designed to feel like an RPG layer on top of chat. A wave system means the story keeps growing: when all realms complete a wave's lore, a Convergence event fires and the next chapter begins.

Systems

Core Systems

🌿 Realm Progression

Every XP-eligible message contributes to both your personal level and your realm's collective level. Realm levels unlock lore chapters, exclusive events, and rank roles.

  • Realm XP is pooled across all members
  • Realm level gates lore chapter unlocks (3, 7, 12, 18, 25…)
  • 3 rank roles per realm at Levels 1, 10, and 25
  • Seasonal items are realm-specific drops
⚔️ Class System

8 archetypes — each with a passive, 3 skill tiers, 5 stats, and unique combat specials. One pick per Wave.

  • Pick with /class pick — no switching mid-wave
  • Two XP tracks: member level (chat) and class level (adventure)
  • Skills unlock at member levels 5, 15, and 30
  • Prestige at Class Level 10 → carry 30% of max stats forward
  • Play all 8 classes → 🏆 Class Master title
🎒 Items & Crafting

Items drop randomly from chat messages into your realm's shared inventory. Combine materials to craft usable items.

  • Common (2.5%), Uncommon, Rare, Legendary drop tiers
  • Realm-specific drops plus universal items
  • Craft with /craft from recipes in /recipes
  • Use items with /use — effects apply realm-wide
  • Seasonal items only drop during their season; fuse with /forge
🗺️ Adventures & Boss Fights

Solo and group dungeon runs earn class XP and items. Server-wide boss fights rally all realms.

  • /adventure — solo dungeon run
  • /adventure_group — party dungeon
  • 11 adventure zones, gated by class level
  • 9 server bosses with phased fights and loot multipliers
  • Curses from traps persist across runs until cleansed
  • Daily weather modifies combat stats server-wide
🏴 Battles & Raids
  • Riddle battles, reaction races, item hunts, word scrambles, XP frenzies
  • /raid — launch a raid against a rival realm
  • /sabotage — sneak in and destroy their items
  • /challenge — trivia duel between realms
  • Events auto-trigger from chat activity or via /admin start-event
🌀 Waves, Seasons & Convergence

The world evolves in waves. When all realms finish a wave's lore, Convergence fires and the next wave begins.

  • Each wave: 5 lore chapters + 3 lore fragments per realm
  • Seasonal items (Spring/Summer/Autumn/Winter) only available during their window
  • Fuse all 3 seasonal items into a powerful Legendary artifact
  • Use /wave to check progress; /season for seasonal status
  • Convergence resets wave progress but carries member history forward
🌦️ Weather & Curses

Two passive world modifiers that affect all combat and adventures.

  • Daily weather changes at midnight — affects Power, Agility, Vitality for everyone
  • Sunny: +Power. Rainy: +Wisdom. Stormy: +Agility. Foggy: -Vitality. Blizzard: -all
  • Curses apply when you trigger traps in dungeons
  • Curse effects persist across all runs until cleansed
  • /curses to view active curses; /cleanse to remove them

Getting Started

Setup Notes

Recommended rollout

Enable realms first. Once people chat and earn XP, introduce classes. Adventures and boss fights layer in after that. Items, quests, events, lore, and seasons add texture over time. No need to introduce everything at once.

1. Create realm roles (one per realm) 2. Create rank roles (3 per realm: Level 1, 10, 25) 3. Fill in role IDs in config/config.py 4. Run /setup realms in your realm-select channel 5. Create lore channels (one per realm) and run /setup lore 6. Set your events channel ID in config 7. Run /setup events to post the persistent dashboard 8. Run /setup wave to post the wave progress embed 9. Restart — quests auto-rotate, events trigger from chat 10. Run /season to verify seasonal content is active 11. Run /wave to check lore wave status 12. Announce /class pick to members — classes are ready out of the box 13. Adventures and boss fights are available immediately
Everything is in one file

All IDs, realm definitions, items, crafting recipes, quests, lore waves, seasonal content, riddles, word scrambles, emoji chains, drop rates, adventure zones, monsters, and boss definitions live in config/config.py.

How it works

Class Fundamentals

🔑 The Basics
  • Pick once per Wave with /class pick — no switching mid-wave
  • Classes are universal — any realm can pick any class
  • Your passive activates the moment you pick
  • Use /class info to compare all 8 before committing
  • View active bonuses with /character
📊 Two XP Tracks
  • Member Level — earned from chatting. Unlocks class skills at Lv 5, 15, and 30
  • Class Level (1–10) — earned only through adventures and boss fights
  • Class level scales your five combat stats
  • Class level determines which adventure zones you can enter
  • The two tracks are completely separate
⭐ Prestige
  • Reach Class Level 10 and run /class prestige
  • Choose any class except the one you're leaving
  • Carry a permanent +30% of your old class's max stats
  • Bonuses stack — each prestige adds another layer permanently
  • Strategy: prestige from high-Power classes (Invoker, Striker) early to build a combat foundation
🏆 Class Mastery
  • Play all 8 classes — current class + full prestige history — to earn 🏆 Class Master
  • Badge appears automatically on /character
  • Requires at least 7 prestiges in a single wave (minimum path)
  • Resets with each Wave; prestige history carries into wave history
📊 The Five Stats

Stats start at base value at CL1 and grow each level to CL10. Use /class stats to see yours.

  • ⚔️ Power — Damage dealt each round. High Power: Invoker, Striker.
  • 📖 Wisdom — Pre-combat heal + bonus adventure XP. High Wisdom: Scholar, Oracle.
  • 🏃 Agility — Crit chance, dodge chance, first-strike prob. High Agility: Trickster, Wanderer, Invoker.
  • 🛡️ Vitality — HP pool for dungeons. High Vitality: Sentinel, Warden.
  • 🍀 Fortune — Loot drop chance + adventure XP bonus. High Fortune: Wanderer, Oracle, Trickster.
🔓 Skill Unlock Reference
Remember

Skills unlock from member level (chat), not class level (adventures).

  • Level 5 — Skill 1 unlocks (early passive modifier)
  • Level 15 — Skill 2 unlocks (secondary specialisation)
  • Level 30 — Skill 3 unlocks (signature power spike)

Campaign Authoring

How Campaigns Work

Drop a .json file into data/campaigns/. The bot re-scans on every /campaign start — no restart, no code changes.

🗺️ Scene Graph

A campaign is a directed graph of scenes — each has a type, text, and either a single next pointer or branching choices. The engine walks until it hits an ending.

💾 Persistent State

HP damage, ability cooldowns, party buffs, and found items all carry forward through the entire run. Early decisions have real consequences at the boss. Vote timeout: 90 seconds, leading choice wins.

Scene Types

Scene Reference

📖 story — Narration & Choices

The workhorse. Include choices for a party vote; omit them and use next to auto-advance after 4 seconds.

With choices (party vote)

"my_scene": { "type": "story", "title": "The Cracked Gate", "text": "The ruins loom...", "choices": [ { "id": "scene_a", "label": "Take the main corridor", "emoji": "🚪", "hint": "Straightforward but exposed" } ] }

Auto-advance (no vote)

"cutscene": { "type": "story", "title": "A Beat of Silence", "text": "The dust settles...", "next": "next_scene_id" }
⚔️ combat — Monster Fights

Party fights a monster. HP scales with party size: hp × (1 + 0.70 × (party_size − 1)).

"forest_ambush": { "type": "combat", "title": "Ambushed!", "text": "Something lunges from the dark...", "enemy": { "name": "Ruinspawn", "emoji": "👹", "hp": 80, "attack": 18, "defense": 8, "speed": 12 }, "loot": ["Tarnished Cog", "Rusted Bolt"], "on_win": "next_scene_id", "on_lose": "defeat" }
Required

Every combat scene must have both on_win and on_lose. Missing on_lose errors out.

💀 boss — Phased Final Battle

Phased boss fight. HP: hp + hp_per_fighter × (party_size − 1). Phases must be highest threshold first.

"boss_ruinlord": { "type": "boss", "title": "The Ruinlord Awakens", "text": "An ancient colossus rises...", "enemy": { "name": "The Ruinlord", "emoji": "🐉", "hp": 350, "hp_per_fighter": 80, "attack": 28, "defense": 18, "speed": 8, "loot_multiplier": 2.0 }, "phases": [ { "threshold": 50, "text": "The Ruinlord rages!" }, { "threshold": 25, "text": "It burns with desperation..." } ], "on_win": "victory", "on_lose": "defeat_boss" }
🎁 item — Treasure Rooms

Grants items with optional HP and XP bonuses. Must have a next pointer.

"treasure_vault": { "type": "item", "title": "The Hidden Vault", "text": "Shelves of forgotten relics...", "items": [ { "name": "Ember Shard", "emoji": "🔴", "description": "Warm to the touch.", "hp_bonus": 0, "xp_bonus_percent": 15 } ], "next": "after_vault" }
⛺ checkpoint — Rest Room & 🏁 ending — Terminal Scene

Checkpoint — Heals entire party, waits until all click ✅ Ready.

"vault_rest": { "type": "checkpoint", "title": "Antechamber", "text": "A heavy door seals...", "next": "boss_scene" }

Ending — Terminal scene. Always set xp_reward on win or everyone gets 0 XP.

"victory": { "type": "ending", "outcome": "win", "title": "Ruins Fall Silent", "text": "The Ruinlord dissolves...", "xp_reward": 250 }

Rewards

XP Formula & Scaling

How it's Calculated

  1. Reads xp_reward from the win ending
  2. Each member's share scales by damage dealt: base × (0.6 + 0.4 × damage_share)
  3. KO'd players receive 40% of their share
  4. Multiplied by any xp_bonus_percent from items

Scaling Reference

Monster HP: hp × (1 + 0.70 × (party_size − 1)) Boss HP: hp + hp_per_fighter × (party_size − 1) XP per player: base × (0.6 + 0.4 × dmg_share) × (1 + xp_bonus_pct / 100) KO'd: 40%

Best Practices

Dos & Don'ts

✅ Do This

  • Converge paths before the boss. Two separate bosses doubles your writing work.
  • Put item scenes after hard fights. Natural reward cadence — HP bonus helps.
  • Give every path something. If path A has a treasure, give path B intel or a shortcut.
  • Have at least 2 lose endings. Different text for early vs. boss fails.

❌ Avoid This

  • Missing scene IDs. A broken next or on_win pointer errors and ends the campaign.
  • Forgetting on_lose. Required on every combat scene.
  • HP bonuses on combat loot. Combat loot is display-only — use an item scene instead.
  • Missing xp_reward. Boss awards 0 XP without it.
  • Phases in wrong order. Must be highest threshold first.

Before you ship

Validation Checklist

  • Valid JSON — paste into jsonlint.com
  • start_scene exists in "scenes"
  • Every on_win, on_lose, next, and choice id points to a real scene
  • Every combat has both on_win and on_lose
  • Every item, checkpoint, and auto-advance story has next
  • At least one ending with "outcome": "win"
  • Win ending has xp_reward set to non-zero
  • Boss phases ordered highest threshold first
import json data = json.load(open("my_campaign.json")) scenes = data["scenes"] all_ids = set(scenes.keys()) errors = [] for sid, scene in scenes.items(): for field in ["next","on_win","on_lose"]: t = scene.get(field) if t and t not in all_ids: errors.append(f"{sid}.{field} → not found") for c in scene.get("choices", []): if c["id"] not in all_ids: errors.append(f"{sid} choice not found") if errors: for e in errors: print("ERROR:", e) else: print("OK")
