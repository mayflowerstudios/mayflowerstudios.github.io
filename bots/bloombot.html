📝 Description

What BloomBot actually does

BloomBot is a public Discord bot focused on practical community features: welcoming new members, handling self-assignable roles, celebrating birthdays, posting daily affirmations, tracking chat XP, and unlocking achievements tied to server activity.

It's built around slash commands and per-server settings, so each community can decide which systems to enable, where announcements should go, and how much automation they want.

🌼 Built for Community Servers

BloomBot is a good fit for gaming servers, cozy friend groups, fandom servers, and growing communities that want helpful automation without feeling bloated.

  • Custom welcome and leave channels/messages
  • Saved-message reaction role panels
  • Birthday tracking and automatic birthday posts
  • Daily affirmations with optional custom messages
  • XP, level-ups, leaderboards, and achievements
Public bot note

BloomBot is meant to be invited to multiple Discord servers, with each server able to configure its own channels, toggles, and settings independently.

The real BloomBot feature set

BloomBot can post customizable join and leave messages in channels you choose.

🏷️ Message Tags

Easy template placeholders for custom messages

Some BloomBot messages can be customized with simple tags. When the message sends, BloomBot replaces each tag with the right info automatically.

Example

If your welcome message is:
Welcome {mention} to {server}! You are member #{membercount} 🌸

BloomBot might send something like:
Welcome @Luna to Cozy Garden! You are member #142 🌸

Available Tags

  • {mention} — mentions the member directly
  • {user} — the member's display name / server nickname
  • {username} — the member's Discord username
  • {server} — the server name
  • {membercount} — the current member count
  • {age} — the person's birthday age as a number (birthday messages only)
  • {age_ordinal} — the age written like 18th, 21st, etc. (birthday age messages only)

👋 Welcome + 🍂 Leave Messages

These support:

{mention}, {user}, {username}, {server}, {membercount}

🎂 Birthday Messages

These support everything above, plus:

{age}, {age_ordinal}

Ready-to-Use Examples

  • Welcome: Welcome {mention} to {server}! You are member #{membercount} 🌸
  • Leave: {user} has left {server}. 🍂
  • Birthday: 🎉 Happy Birthday {mention}! Hope you have a lovely day 🌸
  • Birthday with age: 🎉 Happy {age_ordinal} Birthday {mention}! Hope you have a lovely day 🌸

📘 How to Use

Step-by-step setup guide

Step 1 — Invite BloomBot

Click the Invite BloomBot button at the top of this page, choose your server, and approve the permissions. Make sure BloomBot's role is above any roles you want it to assign via reaction roles.

Step 2 — Set Your Timezone

This controls when birthday and affirmation posts happen. Do this first so everything else uses the right time.

/settimezone

Step 3 — Welcome + Leave Messages

Pick a channel for each, then customize the message templates using the tags listed above. You can enable or disable either one independently.

/setwelcomechannel #welcome /setwelcomemessage Welcome {mention} to {server}! 🌸 /setleavechannel #general /setleavemessage {user} has left {server}. 🍂

Step 4 — Reaction Roles

Post a message in your roles channel first (the message you want members to react to), then save it as a panel and add emoji → role mappings.

/reactionroles create panel_name:colors message_id:123456789 channel:#roles /reactionroles addreaction panel_name:colors emoji:🔴 role:@Red /reactionroles addreaction panel_name:colors emoji:🔵 role:@Blue

Step 5 — Birthdays

Set a channel for birthday posts. Members save their own birthdays, and BloomBot announces them automatically. You can customize the message templates and toggle announcements on/off.

/setbirthdaychannel #birthdays /togglebirthdays enabled:True

Members use: /setbirthday month:3 day:15 (year is optional)

Step 6 — Daily Affirmations

Pick a channel and time for daily positive messages. You can also add your own custom affirmations.

/setaffirmationchannel #positivity /setaffirmationtime hour:9 minute:0 /toggleaffirmations enabled:True

Step 7 — Leveling + Achievements

Turn on XP leveling and achievements. Optionally set channels for level-up and achievement unlock announcements — if you don't, they'll post in the channel where the trigger happened.

/toggleleveling enabled:True /setlevelupchannel #level-ups /toggleachievements enabled:True /setachievementchannel #achievements
💡 Tip

You don't have to set up everything at once. Start with welcome/leave and reaction roles, then add birthdays, affirmations, leveling, and achievements once your community is active. Every system can be toggled on or off independently.

🔧 Setup Notes

Good things to know
Permissions

BloomBot needs Manage Roles for reaction roles to work. Its bot role must be placed above any roles you want it to assign in your server's role list. All admin commands require the Administrator permission.

Toggles

Every major system (welcome, leave, birthdays, affirmations, leveling, achievements) can be toggled on or off independently. Turning something off keeps your settings saved — you can turn it back on later without reconfiguring anything.

Timezone

The server timezone (set with /settimezone) controls when birthday checks and daily affirmation posts happen. It defaults to America/New_York if not set.
