📝 Description

What BloomBot actually does

BloomBot is a public Discord bot focused on practical community features: welcoming new members, handling self-assignable roles, celebrating birthdays, tracking chat XP, and unlocking achievements tied to server activity.

It’s built around slash commands and per-server settings, so each community can decide which systems to enable, where announcements should go, and how much automation they want.

🌼 Built for Community Servers

BloomBot is a good fit for gaming servers, cozy friend groups, fandom servers, and growing communities that want helpful automation without feeling bloated.

  • Custom welcome and leave channels/messages
  • Saved-message reaction role panels
  • Birthday tracking and automatic birthday posts
  • XP, level-ups, leaderboards, and achievements
Public bot note

BloomBot is meant to be invited to multiple Discord servers, with each server able to configure its own channels, toggles, and settings.

⭐ Core Systems

The real BloomBot feature set

👋 Welcome + Leave Messages Core

BloomBot can post customizable join and leave messages in channels you choose.

  • Separate welcome and leave channels
  • Separate welcome and leave messages
  • Enable/disable both systems independently
  • Supports placeholders like {user}, {server}, and {membercount}

🎭 Reaction Roles Popular

BloomBot uses a saved-message workflow for reaction roles instead of generating a brand-new panel message.

  • Point BloomBot at an existing message
  • Save it under a panel name
  • Add emoji → role mappings
  • Members gain or lose roles when they add/remove reactions

🎂 Birthday System Community

Members can save birthdays, and BloomBot automatically checks for birthdays throughout the day.

  • Optional year support when saving a birthday
  • Automatic birthday announcement channel
  • Age-aware birthday messages when year is provided
  • Timezone used by the bot is America/New_York

✨ Leveling Progression

Members earn XP by chatting, with built-in cooldown pacing and level-up announcements.

  • XP earned from normal server messages
  • 60-second XP cooldown per member
  • Random XP gain between 15 and 25
  • Custom level-up announcement channel

🏆 Achievements Extra

BloomBot includes an achievement system tied to chatting, reactions, joining, birthdays, and leveling.

  • Automatic unlock announcements
  • Optional achievement images
  • Member achievement view + leaderboard
  • Admin controls for toggling and manually granting achievements

🛡️ Admin Controls Staff

Most setup commands are admin-only so server owners can configure BloomBot safely.

  • Channel selection commands for major systems
  • Toggle commands for welcome, leave, leveling, and achievements
  • Manual XP and level adjustment tools
  • Saved reaction-role config management

📘 How to Use

Recommended setup flow

1) Invite BloomBot

Add BloomBot to your server with the invite button above.

  • Choose the server you want to add it to
  • Approve the requested permissions
  • Make sure BloomBot can manage any roles you want it to assign

2) Set Welcome + Leave

Pick channels and customize the messages members will see when people join or leave.

  • Set a welcome channel and/or leave channel
  • Customize each message separately
  • Turn either system on or off whenever needed

3) Build Reaction Role Panels

Use an existing message as the base, then attach role mappings to it.

  • Create a saved panel from a message ID
  • Add emoji-to-role mappings
  • Let members self-assign roles by reacting

4) Enable Community Features

Turn on birthdays, leveling, and achievements for a more lively server.

  • Choose birthday and level-up announcement channels
  • Let members save their birthdays
  • Track levels, XP, and achievement progress automatically

⌨️ Command Reference

Real commands from the current bot files

👤 Member Commands Use

  • /setbirthday — save your birthday
  • /mybirthday — view your saved birthday
  • /removebirthday — remove your saved birthday
  • /rank — check your level and XP
  • /leaderboard — view the server XP leaderboard
  • /achievements — view your achievements or another member’s
  • /achievementleaderboard — show top members by unlocked achievements

🛡️ Welcome + Leave Admin Commands Staff

  • /setwelcomechannel
  • /setleavechannel
  • /setwelcomemessage
  • /setleavemessage
  • /togglewelcome
  • /toggleleave

🎭 Reaction Role Admin Commands Staff

  • /reactionroles create — save an existing message as a reaction-role panel
  • /reactionroles addreaction — add an emoji → role mapping
  • /reactionroles remove — remove a mapping
  • /reactionroles list — list saved configs
  • /reactionroles show — show one panel’s mappings and link

🔧 Setup Notes

Best way to roll BloomBot out
Recommended rollout

Start with welcome/leave and reaction roles first. Then add birthdays, leveling, and achievements once your community is active and you’ve picked the channels you want BloomBot to use.

Suggested setup: - Invite BloomBot to your server - Run /setwelcomechannel and /setwelcomemessage - Optionally run /setleavechannel and /setleavemessage - Make a role-selection message, then use /reactionroles create - Add emoji mappings with /reactionroles addreaction - Set a birthday channel with /setbirthdaychannel - Turn on leveling or choose a level-up channel with /setlevelupchannel - Set an achievement channel if you want unlock posts in a specific place
